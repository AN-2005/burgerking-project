# 🍔 BurgerKing Website

A modern and responsive BurgerKing-style landing page built using pure HTML and CSS. This project showcases a clean UI design with sections like hero, menu, features, chefs, and more.

---

## 🚀 Features

* 🔥 Attractive Hero Section with background overlay
* 🍔 Menu cards with hover effects
* ⭐ “Why Choose Us” feature section
* 👨‍🍳 Chef showcase section
* 💬 Customer testimonial section
* 📱 Responsive design for mobile devices
* 🎨 Smooth UI with modern styling

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* Google Fonts (Poppins)
